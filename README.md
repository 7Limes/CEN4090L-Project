# CEN4090L Project -- RuneReport

**Our project for CEN4090L tests Old School RuneScape Grade Exchange trading strategies against rel price history.**

Most of the available tools tell you what to buy right now. What about if you don't have that capital? RuneReport answers a different question: *would this strategy/investment have worked?* You define rules for when to buy and when to sell, and RuneReport will replay it against the item's historical prices while enforcing the game's real constraints: buy limits, the 2% GE tax, and a finite number of trade slots.

RuneReport does not recommend trades. It measures strategies you give it. 

> Senior capstone project for CEN4090L (Software Engineering Capstone) at Florida State University.

## Data Source

Price data comes from the [OSRS Wiki Real-time Prices API](https://oldschool.runescape.wiki/w/RuneScape:Real-time_Prices), a partnership between the Old School RuneScape Wiki and RuneLite.
- '/mapping': item names, IDs, buy limits, and alch values.
- '/latest': current instant-buy and instant-sell prices for all items.
- '/timeseries': price history for a single item.
